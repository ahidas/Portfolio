## Embedded Systems Projects

### [Automated Drink Dispenser]()
A microcontroller-based drink dispenser using sensors and interrupt-driven logic to automate safe, accurate pours.

- **Tech:** C, STM32, PlatformIO, I2C, LCD Display
- **Highlights:**
  - Integrated multiple I2C peripherals and sensors
  - Developed interrupt handlers and a custom state machine
  - Accurate pours with real-time display of fill percentage

---

### Banana Emulator *(Private – Available on Request)*
Emulator for a fictional `.SLUG` instruction set running classic games like Flappy Bird and Snake.

- **Tech:** C++, SDL2, Git, CMake, Xcode Instruments
- **Highlights:**
  - Maintained 60 FPS through instruction and rendering optimizations
  - Developed in a 5-person team using Git for collaboration
  - Used profiling tools for memory and performance analysis

## Full-Stack + Tools Projects

### [Words With Buddies]()
A Scrabble/Words With Friends bot powered by a C backend, with a full web interface and account support.

- **Tech:** C, Python (Flask), React.js, SQL, Netlify
- **Highlights:**
  - C bot computes optimal moves based on board and rack
  - Flask API connects React frontend with C executable
  - SQL database supports user accounts and saved game states
